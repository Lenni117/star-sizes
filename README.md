# STAR SIZES

Mobile size comparison of 16 stars drawn to a common scale. Single static file: `index.html`.

## Data and attribution
- Named stars: JMDC measured angular diameters (Duvert 2016) with distances from the HYG database v4.1 (CC BY-SA 4.0, https://github.com/astronexus/HYG-Database). Temperatures are derived from B-V colour.
- O stars: IACOB spectroscopy (Holgado et al. 2018), radius and luminosity derived.
- Red supergiant KY Cyg: Levesque et al. 2005. Yellow hypergiant RW Cep: 2026 survey (arXiv:2602.02449).
- White dwarfs: Gaia EDR3 catalogue, Gentile Fusillo et al. 2021.
- Ages are rough typical-lifetime ranges and are labelled as estimates in the page.

- Typeface: Arcon Regular by Martin Zarth, SIL Open Font License 1.1 (see `OFL-Arcon.txt`), embedded unmodified.

Because the HYG data is CC BY-SA 4.0, this page is shared under CC BY-SA 4.0 as well.
